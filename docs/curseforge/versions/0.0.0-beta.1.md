<h2>v0.0.0-beta.1 - First release: Rustic on NeoForge 1.21.1</h2>

<p>First public build of <strong>Rustic Hearth</strong>, a NeoForge 1.21.1 fork of <strong>Rustic Revived</strong> (NadienDev, MIT), itself a port of <strong>Rustic</strong> by cadaverous-eris and the-realest-stu. <strong>The code and assets have been modified.</strong></p>

<h3>Features</h3>
<ul>
<li><strong>Decoration and storage</strong>: chairs and tables in every vanilla wood plus olive wood and ironwood, cabinets, pots and vases, candles, chandeliers and iron lanterns, slate, stone pillars, clay walls, painted wood, iron lattice, ropes, chains and gargoyles.</li>
<li><strong>Farming</strong>: grapes, olives, tomatoes, chili peppers, wildberries and ironberries, apple trees, ironwood and olive trees, crop stakes, fertile soil, apiaries and bees, and herbs to forage or grow.</li>
<li><strong>Brewing and alchemy</strong>: barrels and brewing barrels for booze, liquid barrels, crushing tub, evaporating basin, condenser and advanced retort to craft elixirs, and the in-game Almanac.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Forked from Rustic Revived 1.0.0 and renamed: mod id and namespace <code>rustic_hearth</code> (it does not clash with Rustic or Rustic Revived), NeoForge 21.1.249, Java 21.</li>
<li>Removed the optional integrations with CraftTweaker, KubeJS, Dynamic Trees and InvTweaks. JEI and Quark remain optional.</li>
</ul>

<blockquote>
<strong>Beta:</strong> the mod builds and the dedicated server starts cleanly, but it has not been played in-game yet. Expect rough edges. This is an unofficial fork, not affiliated with the original authors.
</blockquote>
