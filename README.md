# Cottagecraft

A rustic cottage-core mod for Minecraft 1.21.1 (NeoForge) about decoration, agriculture, brewing
and alchemy.

## Origin

Cottagecraft is a fork of **Rustic Revived** by NadienDev, itself a NeoForge port of **Rustic**
(Minecraft 1.12.2) by cadaverous-eris and the-realest-stu.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.249
